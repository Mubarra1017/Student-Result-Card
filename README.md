# 🎓 Student Result Card

A simple and user-friendly **Student Result Card / Marksheet Generator** built using HTML, CSS, and JavaScript.

This project allows users to enter student information and subject marks and generate a result card.

## 🚀 Live Demo

[View Live Project](https://mubarra1017.github.io/Student-Result-Card/)

## 📌 Features

- Enter student name
- Enter father's name
- Enter roll number
- Enter class
- Enter marks for multiple subjects
- Generate student marksheet
- Calculate total marks
- Calculate percentage
- Display student result
- Simple and clean user interface
- Responsive design

## 📚 Subjects

The project includes the following subjects:

- English
- Urdu
- Mathematics
- Physics
- Computer
- Chemistry
- Islamiyat
- Pakistan Studies
